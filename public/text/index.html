What it does

Browse movies, shows, books, and music. Request something, follow its progress, and get notified when it is ready. Manage your media services and investigate stuck downloads from your phone or browser.

  • Let your household request titles, with approval rules you choose.
  • See what is available, requested, or downloading.
  • Manage Radarr, Sonarr, Chaptarr, Lidarr, and download clients.
  • Inspect service messages and review fixes for stuck imports.
  • Use your own server or NAS. Cantinarr is free and open source under AGPL-3.0.

Run the server

Cantinarr needs a server. The phone apps connect to it.

  1. Save the following as compose.yml on a machine running Docker.
  2. Run docker compose up -d from that directory.
  3. Open http://your-server:8585 in a graphical browser and follow the setup wizard.
  4. Connect your media services, then connect the app to your server.
services:
  cantinarr:
    image: ghcr.io/windoze95/cantinarr:latest
    ports:
      - "8585:8585"
    volumes:
      - ./config:/config
    environment:
      # Optional push notifications
      - CANTINARR_PUSH_GATEWAY_URL=https://push.cantinarr.com
    restart: unless-stopped

Read the setup guide for the full instructions.

Optional AI features

You can connect an AI provider for media requests, service management, and proposed repairs. Browsing, requesting, and service management work without one.

Get the app

  • Google Play for Android.
  • Use the web app in a graphical browser at your server address.
